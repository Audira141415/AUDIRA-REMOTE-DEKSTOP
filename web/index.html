Knowledge Base

Frequently Asked Questions

Technical specifications, encryption guarantees, and deployment answers.

How does Audira Desk achieve zero-latency remote control compared to AnyDesk/TeamViewer?
Audira Desk implements direct peer-to-peer UDP hole-punching. When both peers establish a direct route, screen frames and input packets bypass intermediate servers completely. Additionally, hardware-accelerated video codecs (AV1 and VP9 via NVENC/QuickSync/VAAPI) compress screen frames within 16 milliseconds at 60 FPS, with WASAPI audio loopback encoded via Opus.
Is installation required, or can it be executed as a standalone portable tool?
Audira Desk is packaged as a single standalone executable. Double-clicking AudiraDesk.exe runs the application immediately without administrative rights or registry footprint. If persistent unattended access or Windows UAC elevation is desired, users can click "Install" at any time to register the elevated system service.
What cryptographic algorithms are used for end-to-end encryption?
All cryptographic operations are backed by Libsodium. Session authentication and key exchange use Curve25519 (X25519), while symmetrical stream payload encryption uses ChaCha20-Poly1305 authenticated encryption (AEAD). Relay servers (hbbr) only forward encrypted byte packets and possess zero ability to decrypt video, keystrokes, or clipboard data.
Can Audira Desk interact with Windows UAC elevation and Secure Desktop?
Yes. When installed on the target machine, Audira Desk registers an elevated Windows background service (Audira Desk service running as NT AUTHORITY\SYSTEM). This service hooks into Windows Secure Desktop sessions, allowing remote technicians to accept administrator prompts and inject Ctrl+Alt+Del commands seamlessly.
How do I point clients to my private relay server on Proxmox or a VPS?
Buka Audira Desk > Pengaturan > Jaringan. Masukkan alamat IP atau domain server relay Anda pada kolom Server Rendezvous, serta masukkan kunci publik cluster (dari file id_ed25519.pub) pada kolom Key. Semua koneksi client akan otomatis terenkripsi dan terhubung melalui infrastruktur privat Anda!
